# 🌹 Roses Webpage (Task 8)

## 📋 Description
This project is a simple interactive webpage that displays images of roses in different colors.  
The functionality is implemented using JavaScript and the DOM.

## ⚙️ Features
- Dropdown menu to select rose color  
- Image changes based on selected color  
- Image enlarges smoothly on hover  
- Clicking the image adds a message to a list  
- Moving the mouse away resets the image and clears the list  

## 🛠️ Technologies Used
- HTML  
- CSS  
- JavaScript  

## ▶️ How to Run
1. Download or clone the repository  
2. Open `flowers.html` in a web browser
